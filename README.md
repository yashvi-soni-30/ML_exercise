
# Machine Learning Lab

A collection of machine learning experiments and
implementations using Python and Scikit-learn.

## Project: Iris Flower Classification

### Objective
Predict the species of an Iris flower using
its sepal and petal measurements.

### Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

### Algorithm
K-Nearest Neighbors (KNN)

### Dataset
Built-in Iris dataset from Scikit-learn.

### How to Run

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the training script:

   python train.py

### Evaluation
The model is evaluated using:
- Accuracy
- Classification Report
- Confusion Matrix
